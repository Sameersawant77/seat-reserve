# Seat Reservation at Scale

Spring Boot + PostgreSQL service for atomic seat reservations under high concurrency.

## Quick start (Docker)

```bash
docker compose up --build
```

API: `http://localhost:8080`

## Local development

1. Start PostgreSQL (or use Docker only for DB):

```bash
docker compose up db
```

2. Run the app:

```bash
./gradlew bootRun
```

Environment (defaults in `application.properties`):

| Variable | Default |
|----------|---------|
| `SPRING_DATASOURCE_URL` | `jdbc:postgresql://localhost:5432/reserve` |
| `SPRING_DATASOURCE_USERNAME` | `reserve` |
| `SPRING_DATASOURCE_PASSWORD` | `reserve` |
| `AUTH_HMAC_SECRET` | change in production |
| `HOLD_TTL_SECONDS` | `120` |
| `PER_USER_LIMIT` | `4` |

## Auth

Mint a bearer token (dev helper):

```bash
curl -s -X POST http://localhost:8080/auth/token \
  -H 'Content-Type: application/json' \
  -d '{"user_id":"alice","role":"USER","ttl_seconds":3600}'
```

Admin token: `"role":"ADMIN"` for `POST /shows`.

Identity on reserve/cancel/confirm comes **only** from the token.

## API

- `POST /shows` — create show (admin)
- `GET /shows/{id}` — seat map + counts + reconciliation flag
- `POST /shows/{id}/reserve` — hold seats (all-or-nothing, idempotent)
- `POST /reservations/{id}/confirm` — confirm held seats
- `POST /reservations/{id}/cancel` — release hold (owner only)

Multi-seat reserve is **all-or-nothing**: if any seat is unavailable, the request returns **409** and no seats are held.

## Health & metrics

- Liveness: `GET /healthz`
- Readiness (DB checked): `GET /readyz`
- Prometheus: `GET /actuator/prometheus`

## Build & test

Gradle 9 requires **JDK 17+** to run the wrapper (the app targets **Java 21**). On Windows PowerShell:

```powershell
$env:JAVA_HOME = "C:\Program Files\Java\jdk-21.0.10"
.\gradlew.bat build
```

(`gradle.properties` may set `org.gradle.java.home` for local builds.)

## Burst test

Requires **bash**, **curl**, and a running API (`jq` optional for nicer JSON output):

```bash
bash burst.sh http://localhost:8080 200 500 32
# BASE_URL  CONCURRENCY  HOT_USERS  MAX_PARALLEL(curl workers)
```

Or: `make burst BASE_URL=http://localhost:8080`

Exit code `0` when hot seat A12 has **exactly one** `201`, there are **no 5xx** responses, and show state **reconciles**.

Prints HTTP outcome distribution, reconciliation from `GET /shows/{id}`, and a metrics snapshot.

## Deploy (Render)

1. Push this repo to GitHub.
2. Create a **Blueprint** from `render.yaml` (web service + free Postgres).
3. Set `AUTH_HMAC_SECRET` (generated by blueprint).
4. Live URL: set in Render dashboard after deploy (update this README with your URL).

`DATABASE_URL` or `postgres://` `SPRING_DATASOURCE_URL` values are converted to JDBC automatically.
